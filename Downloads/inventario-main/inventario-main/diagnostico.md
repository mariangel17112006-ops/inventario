## Conceptos Básicos

1. **Diferencia entre java y javac:** `javac` es el compilador que traduce el código fuente `.java` a bytecode (`.class`); `java` es la máquina virtual (JVM) que ejecuta ese bytecode.
2. **Función de Git:** Sistema local de control de versiones para registrar el historial de cambios del proyecto paso a paso.
3. **¿Git y GitHub son lo mismo?:** No. Git trabaja de manera local en el computador; GitHub es la plataforma en la nube donde se alojan y comparten los repositorios remotos.
4. **Glosario:**
   - **Repositorio:** Carpeta administrada por Git que contiene todo el proyecto y su historial.
   - **API:** Interfaz que permite la comunicación e intercambio de datos entre sistemas.
   - **Método HTTP GET:** Método utilizado para solicitar o consultar información de un servidor sin modificarla.
